## Что выполнить

1. R-04: непрерывная CSS-бегущая строка с исходной фразой. Одинаковые группы должны стыковаться без скачка/пустого промежутка, включая mobile/tablet. Текст/скорость в runtime JSON, повторяющиеся CSS-значения в токенах. Декоративные копии aria-hidden, одна читаемая фраза для скринридера. При reduced-motion читаемая статичная фраза без обрезания, движение приостановлено в скрытой вкладке и при keyboard focus/hover в соответствующем блоке. Не добавляй придуманные видимые кнопки/подписи.
2. R-05: нижние призовые карточки перекрывают верхние при скролле и на mobile. Простой local CSS sticky, порядок z-index соответствует порядку трех исходных карточек. Параметры в JSON/токенах. Из final context известны desktop карточки y80/150/220 (шаг70), ширина800/высота480; это статическая геометрия, НЕ авторитетные sticky/duration. Не выдавай выбранные времена/отступы за Figma-факты. Не ставь overflow:hidden на предке sticky, если это блокирует прокрутку окна. У высоких карточек/низкого viewport весь текст должен читаться: при необходимости измеряй реальные высоты ResizeObserver и подбирай top с отрицательным значением; не отключай sticky на всех мобильных. Учитывай длинный внешний JSON, resize/orientation и корректное завершение перекрытия перед следующей секцией. Не обрезай содержание ради эффекта. Desktop-текст блока можно закрепить, если это не мешает низкому viewport.
3. R-08: все реальные кнопки (общие CTA, Да/Нет, menu icon) получают hover для указателя, focus-visible и active для keyboard/touch; ссылки получают доступный интерактив. Используй простые движения/цветовые изменения из имеющейся палитры, честно назови их инженерными demo состояниями. Не имитируй неизвестные точные Figma Hover/Pressed/Inactive. Клик без игры, навигации/форм/внешних бизнес-запросов. Reduced-motion сокращает/убирает движение, focus не обрезается clip-path.
4. Hero Q1 оставь статичным: Q2/Q3 отсутствуют. Не создавай три копии одного вопроса, новые фото, фиктивные вопросы или таймер без доступных вариантов. Не создавай новое раскрытое mobile menu: полный его вид неизвестен; интерактив самой кнопки разрешен. Для этих функций дай конкретные недостающие тексты/изображения/context/state материалы.

Временный Arial уже согласован. Никаких новых production/dev зависимостей, универсальных animation engines/абстракций или настоящей игры. Только доступный P-04, P-05 не начинать. Перед новыми тестовыми файлами сначала предложи их главному агенту по правилам; для этой демо-поведенческой задачи достаточно существующих types/build и точечных проверок без добавления тестового фреймворка. Cleanup всех ResizeObserver/listener обязателен.
