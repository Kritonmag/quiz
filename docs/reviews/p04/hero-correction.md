# P-04 — независимая проверка переключения hero

14.10.2026, PROMPT-016/017. Тот же исполнитель `/root/implementation_p03`, gpt-6-sol/high. Пользователь подтвердил новые тексты screenshot и разрешил Q2/Q3 временно без фотографий. P-04 **ожидает ручной проверки**; эта доработка не означает полного закрытия P-02.

[Открыть страницу на пользовательском порту 4222](http://127.0.0.1:4222/).

Обе кнопки вызывают `nextQuestion()`: Q1 → Q2 → Q3 → Q1. Данные — в `public/mocks/quiz.json`, выбор — локальный signal/computed. Q1 сохраняет исходный PNG; у Q2/Q3 image/imageAlt равны null и `<img>` не создается. Нет оценки правильности, баллов, запросов, автотаймера или подставных фотографий. Для вариантов без фото тексту отдана свободная ширина; высоты карточки 264/246 px сохранены. Добавлено aria-live для вопроса.

Главный агент самостоятельно прочитал изменения относительно [снимка до замечания](hero-correction-baseline.json); отдельная разница — [hero-correction.diff](hero-correction.diff). TypeScript и production build прошли (191.89 kB). Вызваны реальные Angular signal/computed и обработчик 100 раз подряд: порядок корректный, после 100 переходов q2; при каждом возврате q1 возвращается его путь фото. Проверены оба click binding, условный img и 16 случаев фактического JSON guard. Доказательства — [hero-correction-check.json](hero-correction-check.json).

Дополнительно проверена сохранность остального JSON, исходной записи Q1, методов бегущей строки/cleanup, CSS-токенов и пользовательской правки start на 4222. CSS отличается от предыдущего P-04 только двумя правилами ширины текста без фото. Другие секции и оригинальные ассеты не менялись этой доработкой. Новые тестовые файлы/зависимости не добавлены, проверочный модуль использовал имеющийся dev esbuild в игнорируемой `.angular/`.

Это проверка логики с реальным состоянием Angular, **без браузерного DOM/рендера**. Реальные клики, озвучивание aria-live, число строк Q3 и отсутствие визуального перекрытия кнопок не проверены из-за сохраненного ограничения браузерного доступа. Оригинальные фотографии Q2/Q3 все еще необходимы для точного вида Figma; временное отсутствие согласовано явно.

Для единой ручной проверки P-04 перезагрузите страницу. Нажмите Да, затем Нет, затем любую кнопку: должны появиться Q2, Q3 и вновь Q1 с фото. Повторите быстро и с Tab/Enter/Space. На 375 и 320 px проверьте, что весь Q3 читается над кнопками и высота карточки не меняется. Проверьте сохраненные эффекты строки и призов; затем сообщите замечания либо подтвердите приемку доступного этапа с указанными ограничениями.
