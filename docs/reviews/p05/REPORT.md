## Единый маршрут ручной приемки P-05

1. В корне проекта запустить `npm start`, открыть [локальную страницу](http://127.0.0.1:4222/). Для production использовать результат `npm run build`; команда сервера публикуемых файлов здесь не устанавливалась.
2. Проверить ширины 320/375/390/430/768/1024/1280/1440/1920/2560/3840/7680, обе ориентации tablet, высокий DPR и низкое окно: нет случайного горизонтального скролла, обрезания текста и перекрытий. 375/1440 сверить с сохраненными материалами P-02. Эмуляцию 7680 CSS px отметить отдельно от физического 8К устройства.
3. Пройти обеими кнопками полный цикл Q1→Q2→Q3→Q1, проверить соответствие фото, стабильную высоту и читаемость. Посмотреть строку на коротком/длинном тексте, паузу при hover/focus/скрытой вкладке и reduced-motion.
4. Прокрутить призы: начало, промежуточное и финальное перекрытие, нижняя карточка поверх верхней; весь текст доступен, в том числе на mobile/низком окне. Сверить известную финальную геометрию `1:2104`, не требовать отсутствующий PNG как готовое свидетельство.
5. Пройти страницу клавиатурой и touch: фокус видим, кнопки имеют интерактив, переходов/форм/игровых запросов нет. Проверить alt, озвучивание, консоль и сеть. Раскрытое меню остается известным пробелом, его состояние не придумано.
6. Сохранить копию публикуемого `mocks/quiz.json`, изменить текст/параметр без пересборки, перезагрузить и проверить видимое изменение. Проверить loading через замедление запроса и error при недоступном/неверном JSON; затем восстановить файл и обычную страницу.

Это одна приемка всего P-05. После явного подтверждения пользователя статус переводится в `готово` с сохраненными ограничениями; найденные замечания переводят этап в `на доработке`. Коммит в этой задаче не запрошен и не создавался.
