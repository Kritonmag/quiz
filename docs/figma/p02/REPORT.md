## Материалы реализации

Сохранены ровно ресурсы из URL constants успешных get_design_context. PNG — исходные изображения из ответов; SVG — готовые Figma exports векторов. Отдельные детали иллюстраций призов действительно пришли как сотни маленьких SVG; они не были перерисованы, объединены или подменены. Дополнительно Final Scroll State дал готовые групповые SVG для двух первых иллюстраций, полезные для дальнейшей реализации.

Манифест связывает ресурс с ближайшим явно указанным `data-node-id` в дереве JSX. Instance IDs вида `I1:1608;2813:15834` сохранены без выдумывания ID основного компонента. `usages.context` указывает исходный ответ, `assetVariable` — точную константу. Назначение slot для instance берется из секции его экземпляра. Геометрия отображения/маски/transform остается в context; исходный размер PNG не равен размеру слота. Например, исходный PNG сигналиста 1194 × 2000, героический слот в карточке меньше; логотип 567 × 124 отображается через обрезку. Сохраненная вырезка экрана не является заменой этой геометрии.

Визуально просмотрены desktop/mobile screens, Q1 crops обоих устройств, PNG сигналиста, пейзажа с поездом и электромеханика. Проверены корневые размеры/viewBox всех SVG и непустота/формат всех файлов. Векторные иллюстрации видны в исходных screen PNG; самостоятельные render-проверки каждого SVG не выполнялись.

## Предложения AI, отдельно от фактов Figma

- Hero: начать проверку с 4000 ms интервала и 300 ms перехода. Эти значения не извлечены из prototype.
- Строка: непрерывный CSS-трек с одинаковыми копиями; скорость, направление и длительность определить после визуальной проверки. Reduced-motion показывает стабильный текст.
- Призы: попробовать локальный CSS sticky с возрастающим z-index, затем сверить начало/середину/финал и низкий viewport. Статические 70 px шага не назначать автоматически всем мобильным карточкам.
- Breakpoints: выбирать по помещению контента между референсами 375/1440, затем проверять ширины SPEC. Никакой точной tablet-сетки макет сейчас не подтверждает.
- 8K: ограничить ширину контента, центрировать его, растянуть фоны. Конкретный max-width и итоговый вид 7680 × 4320 нужно проверить в P-08; не масштабировать шрифты по ширине полотна Homepage.
