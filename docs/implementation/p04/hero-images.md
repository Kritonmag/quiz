# P-04 — пользовательские PNG для Q2/Q3

По PROMPT-018 два прозрачных портрета добавлены к существующему циклу hero. Первый исходный PNG привязан к Q2 (дежурная по станции), второй — к Q3 (дежурная по вокзалу). [Происхождение, размеры и SHA-256](hero-images.json) записаны отдельно от ассетов Figma P-02. Файлы скопированы побайтно; исходники и 350 файлов `public/assets/figma/` не редактировались.

`public/mocks/quiz.json` содержит новые локальные пути и alt. `quiz-content.ts` разрешает только прежнюю папку `assets/figma/` и новую `assets/hero-user/`, сохраняя проверку пары photo/alt, запрет внешнего адреса, `..` и неподходящего расширения. Возможность `null` для обоих полей оставлена для будущего редактирования JSON; текущие Q1/Q2/Q3 имеют фото.

`hero.component.ts` использует старый `signalist-clip` только для Q1. Портреты Q2/Q3 ставятся отдельным изображением справа, с сохранением соотношения сторон и прозрачности. В mobile-правиле текст обоих вариантов ограничен до 160 px, длинный Q3 дополнительно использует 14/20 px для места над ответами. Высота карточки 264/246 px, положение кнопок, декор и обработчик Да/Нет не менялись. Это локальные инженерные размеры по пользовательскому референсу, а не проверенное соответствие рендеру.

Проверки: `cmp` источника и копии для обоих PNG — совпадение; SHA-256 совпали; `sips` подтвердил 404×500 и 350×504 px, PNG с альфой; `npm run typecheck`, `npm run build` (initial 192.66 kB), `git diff --check` — прошли. Все три изображения существуют в `public/` и после сборки в `dist/quiz-demo/browser/`; валидатор принял текущий JSON и отклонил удаленный путь, `..`, иную папку, `.txt` и отсутствующий alt. Прямой вызов прежнего `nextQuestion()` сохранил цикл Q1→Q2→Q3→Q1.

Browser/DOM-рендер не выполнялся по согласованному ограничению. Нужно вручную проверить видимость лиц, границы прозрачных PNG, неперекрытие длинного Q3 с портретом и кнопками на 1440/375/320 px, а также возврат к исходному Q1. Отсутствующие точные Figma context/PNG и шрифты по-прежнему ограничивают пиксельное совпадение.
