# P-04 — переключение вопросов hero по Да/Нет

Доработка по PROMPT-016/017 поверх доступных эффектов P-04. Пользователь разрешил временно показывать Q2/Q3 без фотографий. Источник текстов и вида трех вариантов — `docs/references/hero/2026-10-14-hero-variants.png`; `2026-10-14-current-hero.png` показывает текущее состояние до доработки. Скриншоты использованы только как референсы, не как ассеты приложения.

## Изменения

- `public/mocks/quiz.json`: `hero.question` заменен массивом `hero.questions` с тремя подтвержденными формулировками. Q1 сохранил исходный PNG/alt. У Q2/Q3 `image` и `imageAlt` явно равны `null`.
- `src/app/quiz/quiz-content.ts`: тип массива и проверка ровно трех записей с уникальными непустыми id, текстом и подписями ответов. Фото/alt проверяются парой: оба `null` либо локальный путь изображения допустимого формата и непустой alt. Пустой список, дубликаты, неверные тексты, смешанная пара, удаленный/выходящий из папки/неизобразительный путь отклоняются.
- `src/app/quiz/hero.component.ts`: локальный signal-индекс и computed текущего вопроса. Оба ответа вызывают один `nextQuestion()`, цикл Q1→Q2→Q3→Q1. Нет оценки правильности, баллов, запросов, навигации или таймера. Изображение рендерится только при наличии пути; текст вопроса обновляется через `aria-live="polite"`.
- `src/styles.css`: только для вариантов без фото тексту доступна почти вся ширина карточки. Фиксированные размеры карточки, декоративный SVG и расположение кнопок сохранены; это дает длинному Q3 место над ответами на mobile.

## Проверки

- `npm run typecheck` — прошел.
- `npm run build` — прошел, production initial bundle 191.89 kB.
- `git diff --check` для измененных файлов — прошел.
- Фактический `isQuizContent` принял текущий JSON и отклонил пустой список, дубликат id, пробельный текст, смешанную null-пару, удаленный путь, расширение `.txt` и `..` в пути.
- Реальный метод `HeroComponent.prototype.nextQuestion` вызван 10 раз подряд с заглушкой signal; последовательность `q1,q2,q3,q1,…`, после 10 нажатий — `q2`. Обе кнопки в шаблоне вызывают именно этот метод.
- Проверены только hero/тип/JSON и точечный CSS. Прочие секции, эффекты, зависимости, package/config/lock и оригинальные ассеты не изменялись этим исправлением.

Браузерный рендер, фактическая высота строк Q3, клики мышью/клавиатурой, озвучивание `aria-live` и визуальное совпадение **не проверены** по согласованному ограничению browser gateway. Оригинальные фотографии Q2/Q3 остаются необходимыми для точного вида Figma; временное отсутствие фото разрешено пользователем. Для ручной проверки: нажать Да и Нет в произвольном порядке, убедиться в цикле и возврате фото Q1; проверить Q3 на 375/320 px без наложения текста на кнопки, а затем клавиатуру и озвучивание вопроса.

Проверка runtime JSON контролирует форму локального пути изображения, но не существование произвольного файла на хостинге. Существование исходного PNG Q1 проверено в `public/assets/figma/`.
