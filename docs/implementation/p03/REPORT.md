# P-03 — статическая адаптивная страница

Реализована самостоятельная Angular-страница «Железные факты» по сохраненным контекстам Figma. Это вклад исполнителя для независимой проверки главным агентом, **не приемка этапа пользователем**.

## Состав изменений

- `package.json`, `package-lock.json`, `angular.json`, `tsconfig*.json`, `src/index.html`, `src/main.ts`: Angular 20.3.17, CLI/build 20.3.19, TypeScript 5.9.3, standalone bootstrap с `provideZonelessChangeDetection()`, strict TypeScript, команды запуска/сборки/проверки типов.
- `src/app/app.component.ts`, `src/app/quiz/quiz-content.service.ts`, `quiz-content.ts`: HTTP-загрузка `mocks/quiz.json` при работе страницы; видимые loading/error; проверка обязательных полей и уникальности ID в списках.
- `src/app/quiz/`: отдельные компоненты header, hero, призов, рейтинга, механики, финального CTA и footer. У страницы один `h1`, семантические области, нативные кнопки `type="button"`, текстовые альтернативы для смысловых изображений.
- `src/app/components/button/`: общая кнопка повторяющихся CTA. `src/styles/tokens.css` и `src/styles.css`: цвета, типографика, отступы, адаптивная раскладка, базовый фокус с клавиатуры.
- По независимой статической сверке уточнены: белая SVG-подложка второго слова hero (`1:1596`/`1:275`), рост desktop-призовых карточек по содержимому, геометрия пьедестала шириной 1200 px с аватарами внутри карточек (`1:2022`–`1:2043`) и оригинальными Subtract SVG, линия/ромбы механики (`1:2060`–`1:2064`, mobile `1:764`), нижний декор призов и механики (`1:1937`/`1:2065`).
- `public/mocks/quiz.json`: подтвержденный Q1, три начальных приза, таблица топ-10, механика, CTA, подвал, подписи и alt. Данные не импортируются в TS и не включаются в JS bundle.
- `.gitignore`, `README.md`, `content-provenance.json`: окружение и происхождение контента/стилей.

Исходные фреймы: desktop `1:1588` (1440 px), mobile `1:271` (375 px), hero `1:1589`/`1:273`, карточка Q1 `1:1608`/`1:296`, призы `1:1611`/`1:305`, рейтинг `1:1940`/`1:637`, механика `1:2044`/`1:756`, финальный CTA `1:2067`/`1:786`, footer `1:2081`/`1:810`. Для групповых иллюстраций первых двух призов применены SVG из сохраненного `1:2104`.

## Проверки исполнителя

- `npm install --prefer-offline --fetch-retries=0 --fetch-timeout=10000` — прошло; Angular core/common/compiler/platform-browser 20.3.17, CLI/build 20.3.19 установлены.
- `npm run typecheck` — прошло.
- `npm run build` — прошло; production output `dist/quiz-demo`.
- `public/mocks/quiz.json` синтаксически валиден; все 40 уникальных ссылок на локальные ассеты в JSON/коде/CSS указывают на непустые файлы; временных Figma URL и ссылок на screenshot PNG в реализации нет.
- Локальный dev server: `http://127.0.0.1:4200/`, session ID `76980`. Исходный запуск в sandbox получил `EPERM` на bind; штатная эскалация разрешила старт. Сервер оставлен работающим для проверки главным агентом.

Browser-проверка ширин из SPEC, загрузки/ошибки JSON и доступности не выполнялась: шлюз браузера заблокировал ее, пользователь разрешил продолжить без нее. Статическая сверка и сборка не заменяют визуальную приемку. Новых тестов приложения не добавлено по проектному правилу; критических бизнес-действий здесь нет.

## Ограничения и следующий этап

- Шрифты RussianRail и FSRAIL отсутствуют: применен временный Arial по явному согласию пользователя. Из-за отличия метрик точная визуальная приемка типографики пока невозможна.
- P-02 частичен: не получены изображения/тексты Q2/Q3, отдельные состояния кнопок и мобильного меню, PNG финального перекрытия и параметры motion. Поэтому Q1 и бегущая строка статичны, меню не раскрывается, начальные карточки призов идут обычным потоком.
- P-04 добавит согласованные демонстрационные эффекты и интерактивные состояния после получения недостающих данных или решения пользователя. Текущий код не начинает P-04.
- Ссылки не ведут наружу; юридические URL и реквизиты оставлены явными заглушками из макета. Кнопки не делают бизнес-запросов.
- Промежуточные адаптивные правила и max-width — инженерная интерполяция между 375 и 1440 px; они не выдаются за Figma breakpoints. Требуется ручная сверка на 320, 375, 390, 430, 768, 1024, 1280, 1440, 1920, 2560, 3840 и 7680 CSS px.
